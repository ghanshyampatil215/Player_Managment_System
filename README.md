# 🏏 Player Management System

## 📌 Project Description
Player Management System is a console-based project developed in C language. It helps manage player records using structures, functions, and file handling.

## ✨ Features
- ➕ Add Player
- ❌ Remove Player
- 🔍 Search Player
- ✏️ Update Player
- 📋 Display All Players
- 💾 Save Player Data
- 📂 Load Player Data

## 🛠 Technologies Used
- C Language
- Structures
- Functions
- File Handling
- Dev C++

## ▶️ How to Run
1. Open the project in Dev C++.
2. Compile the source code.
3. Run the program.
4. Choose options from the menu.
